Avancement des capacités

Comme le menu « Capacités » du jeu : note, pour chaque personnage, les capacités que tu as rendues permanentes (commande montée au niveau max). Certaines se cumulent — clique sur les cases ou utilise − / +. Ta progression est enregistrée dans ce navigateur.

Comment fonctionne la sauvegarde ?

  • Automatique, dans ce navigateur : chaque case cochée est enregistrée tout de suite. Tu retrouves ta progression en revenant sur l’app avec le même navigateur, sans compte ni connexion. Attention : la version en ligne et le fichier local ont chacun leur propre sauvegarde.
  • Pas de synchronisation : rien n’est sauvegardé en ligne : ta progression reste dans ce navigateur. Un autre navigateur, un autre appareil ou une navigation privée repartent de zéro, et vider les données du navigateur efface la progression.
  • Exporter : affiche un code de sauvegarde à copier, et propose aussi de télécharger la même progression dans un fichier .json. Les deux contiennent la progression des 3 personnages et s’importent de la même façon. Garde l’un ou l’autre comme sauvegarde, ou envoie-le-toi pour l’utiliser ailleurs.
  • Importer : colle ce code ou choisis le fichier sur l’autre appareil. La progression importée remplace entièrement la progression actuelle des 3 personnages.
